# 투자리그 집계 기준

- 국내·미국 주식과 ETF를 원화 평가액으로 합산해 하나의 순위로 비교한다. 비공개 종목도 성과에 포함한다.
- 최초 참여 시 이번 주에 이미 저장된 원본 포트폴리오 스냅샷이 있으면 가장 이른 확인 날짜부터 보유 이력을 복원한다. 월요일 스냅샷이 있으면 수요일에 참여해도 월요일부터 성과를 불러온다. 이전부터 보유한 종목의 월요일 성과는 직전 금요일(휴장 시 직전 거래일) 종가와 비교한다. 현재 보유량을 과거에 그대로 적용하지 않고 원본 원장으로 날짜별 수량을 복원하며, 새 스냅샷을 과거 기록처럼 만들어 사용하지 않는다. 기존 기록이 없으면 참여 후 첫 종가를 0% 기준으로 삼는다. 재참여 시 미참여 구간을 소급하지 않고, 계산 가능한 성과가 생기면 신규·중도 참가자도 이번 주 순위에 즉시 반영한다. 한 주 전체 기록을 기다리지 않으며, 기록된 기간이 다른 참가자의 집계 시작일을 화면에 함께 표시한다.
- 원본 포트폴리오 변경은 공개 여부와 관계없이 자동으로 동기화한다. 일괄 보유 추가·정정과 CSV 거래 등록도 저장 커밋 후 요청당 한 번 동기화한다. 비공개 종목의 수량·매수·매도 변경도 비공개 상태로 가져오며 순위에 포함한다. 기존 공개 범위를 유지하고, 새 종목은 비공개로 가져온다.

## 원본 보유와 공개의 경계

- 자동 동기화는 공개·리그 참여 설정과 별개다. 비참여·비공개 사용자도 원본 보유는 비공개로 동기화하며, 공개와 순위 참여는 별도 동의 설정으로 제어한다.
- 수동 가져오기도 원본에 보유한 종목만 허용한다. 클라이언트가 보낸 수량·매입가 대신 서버에 저장된 원본 값을 사용하고, 원본에 없는 종목은 `404 PORTFOLIO_HOLDING_NOT_FOUND`로 거절한다. 덮어쓰기로 임시 보유 수량이나 원본에 없는 종목의 계산 이력을 만들지 않는다.
- 시장 값이 없는 레거시 상장 종목은 기존 국내 가격 수집과 동일하게 국내 보유로 분류한다.
- 공개 상세의 비중·평가 수익률에도 리그와 동일한 환율 실제 기준일 검증을 적용한다. 대체 환율만 있으면 해당 값을 비워 둔다.
- 프로필·일별 조회는 요청 안에서 시장 판정을 재사용하고 요청 종료·오류 시 캐시를 비운다. 공개만 유지하고 리그를 나간 사용자의 보유 시장은 현재 참가자 집합과 별도로 판정한다.

## 일별 API와 화면

`GET /api/league/investors/{publicId}/daily-history`는 월요일부터 일요일까지 7개 날짜를 반환한다. 날짜는 수집일이 아닌 각 시장의 거래일이다. 미국 금요일 종가를 토요일에 받아도 금요일 성과를 갱신한다.

주간 그래프에 계산된 수익률이 있으면 그 값을 표시한다. 현재 달력 수집 상태가 대기여도 기존 성과를 대기 문구로 덮지 않으며, 수익률이 없는 주차에만 대기·휴장 상태를 표시한다.

| 상태 | 하루 수익률 | 주간 누적 | 처리 |
| --- | --- | --- | --- |
| 필요한 종가·환율 수집 완료 | 해당 일 성과 | 일별 성과를 복리로 연결 | 순위 반영 |
| 보유한 시장이 모두 휴장 | 0% | 직전 누적 유지 | `CALCULATED`, `MARKET_CLOSED` |
| 한 시장만 휴장 | 휴장 시장의 직전 평가와 열린 시장의 새 평가를 합산 | 통합 누적 | 순위 반영 |
| 한 시장만 보유 | 보유 시장으로 계산 | 통합 누적 | 미보유 시장의 수집을 기다리지 않음 |
| 열린 시장의 종가·필요 환율 누락 | null | 해당 날짜 이후 null | 직전 완료 성과는 유지, 새 날짜 집계 대기 |
| 아직 오지 않은 날짜 | null | null | `PENDING`, `FUTURE_DATE` |
| 거래일 정보 미확인 | null | null | `PENDING`, `CALENDAR_PENDING` |

휴장일에는 성과가 10%에서 0%로 초기화되지 않는다. 하루 변동은 0%, 누적은 10%다. 직전 성과가 없거나 그 전에 데이터 공백이 있으면 휴장일 누적도 만들지 않는다. 휴장 표시를 위한 가상 0%는 DB의 거래일 수익률에 추가하지 않으므로 변동성 표본 수를 늘리지 않는다.

미국 종가를 환산할 때 환율의 실제 기준일도 검증한다. 요청 날짜에 과거 환율이 저장되어 있더라도 해당 종가 날짜의 환율이 아니면 `EXCHANGE_RATE_PENDING`으로 대기한다. 과거 환율로 대체한 캐시는 TTL 후 다시 확인하며, 대체값을 역사적 확정 환율로 영구 고정하지 않는다. 휴장 시장의 평가를 유지할 때는 직전 종가와 해당 종가의 환율을 함께 유지한다.

## 수집과 다음 집계 예고

기본 설정이며 모든 시각은 한국 시간이다. 운영 환경변수로 변경할 수 있다.

| 작업 | 기본 일정 | 대상 |
| --- | --- | --- |
| 미국 거래일 달력 동기화 | 서버 시작 시 누락 확인, 매일 08:00, 18:00 | 전년도~다음 해의 거래일·휴장일; 실패 시 다음 실행에서 재시도 |
| 국내 종가 수집 | 월~금 14:30, 18:30 | 다음 국내 거래일 14시가 지난 날짜; 누락 재시도 |
| 미국 가격·환율 준비 | 월~토 07:00, 16:00 | 현재 수집 코드의 뉴욕 기준 전일까지; 보유 미국 종목과 필요한 환율 |
| 리그 정기 계산 | 월~토 17:20, 19:20 | 준비된 데이터 반영과 미완료 재시도 |

미국 달력 초기화는 오늘뿐 아니라 전년도~다음 해 전체 날짜와 미국 거래 여부의 누락을 확인한다. 공급사 조회와 저장이 성공해 달력이 변경된 경우 리그 전체 재계산을 요청한다. 조회 실패 시 기존 달력을 유지하고 다음 동기화 일정에서 재시도한다.

국내 가격 수집 완료 시에는 정기 일정 외에도 즉시 재계산한다. 현재 뉴욕 기준 전일 제한에 따라 미국 월요일 종가는 화요일 16시 수집 후 17:20 집계를 예고하며, 미국 금요일 종가는 토요일 16시 수집 후 17:20을 예고한다. 국내 금요일 종가는 다음 국내 거래일 14:30부터 수집한다. 따라서 혼합 포트폴리오의 같은 거래일 성과는 필요한 양쪽 데이터를 모두 기다린다.

미국 가격·환율 준비는 최신 계산 버전에서 종가·환율 대기가 남은 가장 이른 날짜를 확인한다. 그 날짜의 직전 미국 거래일 종가부터 다시 준비하므로 주차가 바뀌어도 이전 주 누락과 비교 기준 환율이 재시도 대상에서 빠지지 않는다. 정기 재계산도 같은 미해결 날짜부터 이후 성과를 다시 연결한다. 새 버전에서 해결된 과거 대기 기록과 스냅샷·보유 종목 등 가격 수집으로 해결되지 않는 사유는 이 재시도 시작일에서 제외한다.

`aggregation.expectedAt`은 필요한 시장의 활성 수집 일정과 계산 일정을 조합한다. 미국 또는 환율 수집 대기라는 이유만으로 예정 시각을 비우지 않는다. 첫 기준 종가와 첫 수익률 변화의 예상 시각은 따로 제공한다. 일정이 지나도 필요한 데이터가 없으면 실제 다음 재시도 일정으로 변경한다. 수집·계산 비활성화 또는 거래일 정보 부족 시에는 시간을 추측하지 않는다.

화면은 예고 시각 30초 후 한 번 재조회한다. 이미 지난 시각으로 반복 요청하지 않으며 수동 새로고침과 브라우저 복귀 시 재조회도 지원한다. 예정 시각은 공급사 데이터 제공과 비동기 작업 완료에 따라 달라질 수 있다.

## 개인 성과와 통합 순위의 기준일

- 개인 성과는 본인에게 필요한 종가·환율·계산이 준비된 날짜까지 먼저 갱신한다.
- 통합 순위는 리그에 필요한 시장 데이터가 확보된 공통 기준일까지 모든 참가자를 계산한다. 같은 날짜까지의 성과끼리 비교하며, 참가자의 집계 시작일 차이는 기존처럼 표시한다.
- 공통 기준일과 순위 점수는 하나의 캐시 결과로 보관한다. 캐시 갱신 중 최신 달력 날짜만 먼저 표시하지 않는다.
- 최신 공통 날짜의 계산 결과가 아직 하나도 없으면 이전 날짜의 완료 순위를 유지한다. 최신 기준일에 계산 가능한 참가자가 있으면 갱신하고, 해당 날짜에 필요한 데이터가 누락된 참가자만 제외한다. 이전 점수를 새 기준일의 순위에 섞지 않는다.
- 개인 성과도 데이터 공백 앞의 마지막 연속 완료 결과와 기준일을 유지한다. 공백 뒤 하루 성과가 있어도 누적을 연결하거나 확정 처리하지 않는다.
- 프로필 `performance.asOfDate`는 개인 성과 기준일, `performance.rankingAsOfDate`는 표시된 통합 순위 기준일이다. 두 날짜가 다를 수 있다.
- 순위 화면은 같은 주차·페이지의 재조회 중 기존 결과를 유지한다. 주차·페이지를 바꿀 때는 이전 조건의 결과를 새 조건으로 표시하지 않는다.

예: A의 화요일 성과가 +5.06%, B는 월요일 +3%까지만 준비된 경우 개인 A는 화요일 +5.06%를 보여준다. 통합 순위는 월요일 기준 A +2%, B +3%로 유지한다. 화요일 미국 데이터가 준비되면 화요일 기준으로 함께 갱신한다. 별도 참가자 C의 종목 가격만 누락되면 C의 새 순위만 보류한다.
