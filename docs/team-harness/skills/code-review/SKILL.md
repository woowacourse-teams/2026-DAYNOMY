# 코드 리뷰

1. 승인된 구현·제외 범위와 실제 diff가 일치하는지 확인한다.
2. 기획서, API 명세, ADR과 기존 구조·네이밍을 따르는지 확인한다.
3. 불필요한 추상화와 요청받지 않은 리팩토링이 없는지 확인한다.
4. 백엔드는 계층 책임, DTO·Domain·Entity 분리, 예외·로그 규칙을 확인한다.
5. 프론트엔드는 컴포넌트 책임, 상태 분리, 공통 컴포넌트 재사용, 로딩·빈 화면·오류·입력 검증을 확인한다.
6. 비즈니스 로직·예외·주요 흐름 테스트와 민감정보 노출 여부를 확인한다.
7. CI 검증 누락 여부를 확인한다.

결과는 치명도 순서로 정리하며, 근거 없는 스타일 선호는 지적하지 않는다.
