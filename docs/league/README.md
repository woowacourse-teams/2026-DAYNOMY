## 접근성 회귀 점검

- 화면별 제목과 진입 초점, 비동기 프로필 조회 후 초점 이동을 확인한다.
- 반복 버튼은 종목·거래일·기록 종류로 대상을 구별한다. 팔로우 버튼은 투자자와 동작, 선택 상태를 전달한다.
- 보유 이유·복기 오류는 입력과 연결하고 첫 미작성 입력으로 초점을 옮긴다. 저장 실패 시 오류 안내·초안·재시도 요청 키를 유지하며 저장·취소·삭제 후 초점을 복귀시킨다.
- 순위 페이지 변경 후 페이지 안내 초점과 목록 시작 번호, 공유 종목 선택 안내, 닉네임 필수 입력 검증을 확인한다.
- 네이티브 버튼·링크·라벨·fieldset·dialog, 그래프의 접근 가능한 이름과 장식 이미지 처리를 유지한다. 일반 텍스트 대비는 4.5:1, 큰 글자는 3:1 이상으로 확인한다.

2026-10-15~16 검증 기록에서는 자동 회귀 테스트와 Chrome 키보드·화면 검증을 수행했다. API 계약에 맞는 테스트 응답을 사용했으며, 당시 실제 인증·운영 API 통합, VoiceOver·NVDA 실기와 개선 전후 비교 영상은 미완료였다. 이를 현재 버전의 검증 완료로 간주하지 않는다.
