# 포트폴리오 일괄 편집과 CSV 가져오기

종목 추가 메뉴는 한 종목 추가, 여러 종목 일괄 추가, CSV 파일 업로드로 나눈다.
기존 보유정보는 보유 자산 목록의 `일괄 편집`에서 정정한다.
수동 일괄 추가는 매매 기록이 아닌 현재 보유잔고 등록이며, 매매·거래일·수수료·세금은 입력하지 않는다.

## 수정 가능한 값

- 보유정보 정정: 보유 수량, 종목 통화 기준 평균 매입가(국내 KRW, 미국 USD).
- 신규 보유잔고: 종목, 수량, 종목 통화 기준 평균 매입가. 환율을 입력하지 않는다.
- CSV 거래내역(보조 옵션): 매수/매도, 거래일, 수량, 단가, 수수료, 세금, 미국 거래의 적용 환율.
- 일괄 추가·보유정보 편집은 평단가·현재가·평가금액·손익을 종목 통화로 표시한다. 서로 다른 통화의 평가액을 합산하거나 비중으로 계산하지 않는다.
- 해외 신규 보유잔고의 원화 집계용 참고 원가는 현재 환율을 자동 조회해 유지한다. 이 값은 실제 매입 환율을 복원한 원가가 아니며, 일괄편집의 달러 손익에는 사용하지 않는다.
- CSV 미리보기에서도 미국 거래의 적용 환율을 수정한 뒤 가져올 수 있다.
- 종목 이름·유형·시장·통화는 종목 정보에서 결정한다.
- 현재가, 평가금액, 손익, 비중은 입력받지 않는다. 편집 중 계산값은 저장 전 미리보기다.
- 보유정보 정정은 `ADJUSTED` 이력을 남기며 매수/매도 거래를 만들지 않는다.
- 일괄 추가는 오늘 기준 `OPENING_BALANCE`를 남기며 `BUY`·`SELL` 거래나 과거 거래일을 만들지 않는다. CSV 가져오기는 실제 매수/매도 이력을 추가한다.

## API

기존과 같이 `/api/portfolio`와 `/api/users/me/portfolio` 경로를 지원한다.
인증된 사용자의 포트폴리오에만 적용하며 CSRF 검증을 따른다.

### `POST /api/portfolio/holdings/bulk`

```json
{"holdings":[{"assetId":1,"quantity":3,"averagePurchasePrice":70000}]}
```

1~200개의 신규 보유잔고를 원자적으로 등록한다. 평균 매입가는 원화 기준이다.
기존 `averagePurchasePrice`는 원화 집계 호환성을 위해 유지한다. 해외 종목은 별도의 선택 필드 `nativeAveragePurchasePrice`에 입력한 USD 평단가(소수 넷째 자리까지)를 함께 전송하고 보관한다.
프론트엔드는 신규 종목의 원화 참고 원가에 자동 조회한 현재 환율을 사용한다. 실제 과거 환차손익을 의미하지 않는다.
예: `{"assetId":2,"quantity":2,"averagePurchasePrice":350000,"nativeAveragePurchasePrice":250}`.
이전 데이터에 외화 평단가가 없으면 거래 원장에서 확인 가능한 USD 매입 원가만 복원한다. 원화 잔고만 있는 종목은 추정 환산하지 않고 평단가·달러 손익을 미확인으로 표시하며 정정 시 USD 평단가를 입력한다.
회원 → 포트폴리오 순서로 잠근 뒤 기존 보유 종목·요청 내 중복·존재하지 않는 자산을 검사한다.
전체 검사 이후 보유자산과 오늘의 `OPENING_BALANCE`만 저장한다. 과거 매수 거래·과거 스냅샷은 만들지 않는다.
응답은 201과 `SavedPortfolioResponse`이며 기존 보유자산 및 실현손익도 유지한다.
비회원도 세션 원장에 동일한 `OPENING_BALANCE`를 한 번에 반영한다.

### `PATCH /api/portfolio/holdings`

```json
{"holdings":[{"assetId":1,"quantity":3,"averagePurchasePrice":70000}]}
```

1~200개의 기존 보유 종목을 정정한다. 중복 종목 또는 보유하지 않은 종목은 거부한다.
수정 시에도 `nativeAveragePurchasePrice`를 함께 저장하며 응답에 포함한다. 외화 평단가만 정정할 때 원화 참고 원가는 기존 원가의 환산 비율을 유지하고, 기존 외화 원가가 없는 경우 현재 환율을 조회한다.
응답은 수정 대상의 `SavedPortfolioHoldingResponse` 배열이다.
값이 같은 종목은 추가 이력을 만들지 않는다.

### `POST /api/portfolio/transactions/bulk`
### `POST /api/portfolio/transactions/import`

```json
{"transactions":[{"assetId":1,"type":"BUY","tradeDate":"2026-10-01","quantity":3,"unitPrice":70000,"fee":0,"tax":0}]}
```

기존 단일 거래와 동일한 필드와 검증을 사용한다. 미국 거래는 `exchangeRate`가 필수다.
1~200건을 날짜순으로 적용하며 같은 날짜는 요청 순서를 유지한다.
검증·거래 저장·보유자산 재생·과거 스냅샷 갱신에 하나라도 실패하면 전체를 롤백한다.
비즈니스 오류 메시지에는 원본 요청 배열의 거래 순번을 표시한다.

```json
{"importedCount":1,"alreadyImported":false,"portfolio":{"holdings":[],"totalRealizedProfitLoss":0}}
```

`portfolio`는 저장 완료 후 전체 보유자산과 실현손익이며, 위 예시는 응답 구조만 나타낸다.
프론트엔드는 이 응답을 반영하고 자산 계산·거래 내역·자산 추이를 갱신한다.

`import`는 날짜순 거래 내용의 SHA-256을 포트폴리오별로 저장한다.
숫자의 표기 차이와 국내 거래 환율의 생략/1을 정규화한다.
같은 내용의 CSV를 다시 가져오면 `importedCount: 0`, `alreadyImported: true`로 응답하고 추가 저장하지 않는다.
같은 날짜의 행 순서는 계산에 영향을 주므로 중복 판정에서도 유지한다.
다른 파일에 일부 겹치는 거래는 자동 제거하지 않으며, 기존 개별 거래와의 중복도 추측하지 않는다.
가져온 거래를 나중에 수정·삭제해도 같은 파일의 가져오기 기록은 유지된다.
`transactions/bulk`는 기존 거래 등록 API로 유지한다. 수동 일괄 추가 UI는 위의 `holdings/bulk`를 사용한다. 이미 보유 중인 종목과 같은 요청 안에서 반복된 종목은
`DUPLICATE_PORTFOLIO_ASSET` 오류로 전체 등록을 거부한다. 회원 → 포트폴리오 잠금 이후 검사한다.
검색 결과에서도 `보유 중`·`추가됨`을 표시하고 선택을 막는다.
기존 종목의 추가 매수·매도는 한 종목 추가 또는 CSV 거래 가져오기를 사용한다.

환율은 트랜잭션 밖에서 준비하고, 원장 조회 전에 회원 → 포트폴리오 순서로 잠근다.
스냅샷 갱신은 전체 거래 적용 후 한 번 수행한다.
중복 판정 기록은 V70 마이그레이션의 `portfolio_transaction_imports`에 저장한다.
종목 통화 기준 평단가는 V71 마이그레이션으로 보유자산·원장에 추가한 nullable 필드에 저장한다. 실제 매수 원장 재생은 수수료·세금을 포함한 외화 평균 원가도 별도로 계산하며 매도 후 남은 수량에도 유지한다.

## 보유현황 CSV (기본)

CSV 업로드의 기본 유형은 기존 엑셀 보유종목을 옮기는 `보유현황`이다. 과거 거래가 아닌 현재 보유잔고로 `holdings/bulk`에 등록하고 `OPENING_BALANCE`를 남긴다. 기존 거래내역 업로드는 창 안의 `거래내역` 옵션으로 유지한다. 유형을 변경하면 파일과 미리보기를 초기화하기 전에 확인한다.

```csv
종목코드,종목명,보유수량,평균매입가
005930,삼성전자,10,70000
AAPL,애플,5,200
```

- CSV 500KB·최대 200개 종목. UTF-8(BOM 포함), UTF-16(BOM), EUC-KR을 읽으며 쉼표·탭·세미콜론·파이프 구분자를 탐지한다. 원본 파일은 브라우저에서 처리하고 서버에 업로드하지 않는다. XLSX·PDF·이미지 인식은 포함하지 않는다.
- 파일 선택 후 필수 열이 유일하게 연결되면 확인 버튼 없이 종목 검색·숫자 정규화·미리보기까지 자동 진행한다. 열 연결 설정은 접어 두고 필요할 때 수정할 수 있다. 모르는 열·중복 후보 열만 펼쳐 선택을 요구하며, 마지막 필수 열을 지정하면 별도 미리보기 버튼 없이 자동 반영한다. 최종 가져오기는 사용자가 누른다.
- 첫 20개 행에서 헤더를 탐지하며 구분자·헤더 행(헤더 없음 포함)을 사용자가 바꿀 수 있다. `개수/보유수량/shares`, `평단가/평균매입가/average price` 등 별칭을 연결하고 모르는 열은 직접 지정한다. 동일 의미의 후보 열이 여러 개면 자동 선택하지 않는다. 원본 열 이름과 첫 값도 보여 준다.
- 매매 구분·날짜가 있는 거래내역 파일은 보유현황으로 잘못 등록하지 않고 거래내역 유형을 안내한다.
- 종목명 또는 코드, 수량, 평균 매입가 또는 총 매입금액이 필요하다. 그 밖의 열은 연결하지 않으면 무시한다. 현재가·평가금액·손익은 평단가로 자동 연결하지 않는다.
- 쉼표 천 단위·통화·주/개 단위를 정리하고 국내 코드 앞자리 0과 Excel 문자열 코드를 보정한다. 소수 쉼표, 음수·소수 보유수량, 수식 등은 임의의 유효한 숫자로 바꾸지 않으며 미리보기에서 정정해야 한다.
- 평단가가 없고 총 매입금액이 있으면 수량으로 나눠 계산한다(정수 기반 계산, KRW 소수 2자리·USD 4자리 반올림). `합계/총계/소계/total/subtotal` 행은 제외하고 제외 건수를 표시한다.
- 종목명·티커의 정확한 일치가 하나이고 시장·통화가 맞을 때만 자동 연결한다. 불확실한 종목은 파일의 이름/코드로 미리보기에서 재검색한다. 파일 가격 통화와 선택한 종목 통화가 다르면 평단가를 직접 확인·정정하기 전 저장하지 않는다. 과거 환율로 임의 환산하지 않는다.
- 미리보기에서 수량·평단가 수정, 여러 셀 복붙, 문제 행 삭제를 지원한다. 원본 행 번호를 표시하고 보유 중인 종목·파일 내 중복·미확인 종목·유효하지 않은 값이 남아 있으면 전체 저장을 막는다. 보유현황 CSV 재업로드도 기존 보유 종목 중복으로 막으며 수량을 매수처럼 합산하지 않는다.
- 미국 보유종목은 기존 일괄 추가와 동일하게 USD 평단가를 저장하고 원화 집계용 참고 환율만 자동 조회한다. 현재가 누락은 보유현황 등록을 막지 않으며 미확인 평가액은 `—`로 표시한다.

## 거래내역 CSV 양식 (보조 옵션)

브라우저에서 500KB 이하 UTF-8 CSV를 파싱하고 종목 코드와 시장을 정확히 대조한다.
전체 행이 유효할 때 미리보기를 표시하고, 사용자가 가져오기를 누르면 JSON API로 전송한다.
서버도 모든 거래를 다시 검증한다. 원본 파일과 파일 이름은 서버에 저장하지 않는다.

```csv
assetCode,market,type,tradeDate,quantity,unitPrice,fee,tax,currency,exchangeRate
005930,KOSPI,BUY,2026-10-01,3,70000,0,0,KRW,
AAPL.US,NASDAQ,BUY,2026-10-01,1,250.1234,0,0,USD,1400
```

열 순서는 바꿀 수 있지만 열 이름은 모두 유지한다. 종목 코드는 검색 API가 반환하는 코드를 사용한다.
국내 코드의 앞자리 0을 보존하고, 미국 코드는 `.US`까지 입력한다.
거래 단가·비용은 해당 통화 기준, 환율은 1 USD당 원화 금액이다.
오류는 원본 CSV 행 번호와 함께 안내한다. BOM, CRLF, 따옴표로 묶인 값도 지원한다.
증권사별 양식 자동 인식과 계좌 연동, 현금 잔고 관리는 포함하지 않는다.

비회원은 서버에 저장하지 않고 기존 세션 원장에 전체 변경을 한 번에 반영한다.
CSV 중복 판정도 현재 탭의 세션 범위에서만 유지된다.


## 표시 변경 범위

종목 통화 기준 금액과 손익 옆 수익률 표시는 일괄 추가·편집 창에만 적용한다. 대시보드 목록·버튼·종목 상세는 기존 디자인과 계산 기준을 유지한다.

## 일괄편집 셀 범위 선택

- 창 안의 표에서 마우스 드래그, Shift+클릭, Shift+방향키로 사각형 범위를 선택한다. 터치 스크롤은 유지한다.
- Ctrl/Cmd+C로 선택한 값을 탭·줄바꿈 형식으로 복사해 엑셀이나 편집 표에 붙여넣을 수 있다. 입력칸에서 일부 글자만 선택한 복사와 종목 검색창의 복붙도 유지한다.
- Ctrl/Cmd+V는 선택 범위의 왼쪽 위부터 적용한다. 한 값을 복사해 여러 셀을 선택하면 선택한 칸 전체를 같은 값으로 채운다.
- 보유정보 편집·신규 행·보유현황 CSV의 수량·평균 매입가만 붙여넣을 수 있다. 일괄 추가의 기존 보유 행, 종목·통화·계산값은 읽기 전용이다. 거래내역 CSV 미리보기에서는 미국 거래 환율만 수정한다.
- 붙여넣을 행은 먼저 추가한다. 읽기 전용 칸이나 표 바깥을 덮는 범위는 일부도 변경하지 않고 오류를 표시한다. 여러 행 붙여넣기는 한 번에 되돌릴 수 있다.
- Ctrl/Cmd+D는 선택 범위의 첫 행을 아래로 채우며, 한 행만 선택했으면 바로 위 행의 값을 사용한다. Escape는 범위 선택을 해제한다.
- 선택 상태는 창 안에서만 관리하며 서버 API와 바깥 대시보드에는 변경이 없다.
