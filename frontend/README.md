# DAYNOMY FRONTEND

## 기술 스택

| 항목 | 버전 |
|------|------|
| React | 19 |
| TypeScript | 6.0 |
| Vite | 8.2 |

---

## 필수 설치 항목

- **Node.js 18** 이상 설치
- Git

---

## 환경 설정

### 1. 저장소 클론

```bash
git clone https://github.com/woowacourse-teams/2026-DAYNOMY
cd daynomy/frontend
```

### 2. 의존성 설치

```bash
npm install
```

---

## 빌드

```bash
# 프로덕션 빌드
npm run build
```

빌드 결과물은 `dist/` 폴더에 생성됩니다.

---

## 실행

```bash
# 개발 서버 실행
npm run dev
```

서버가 정상 기동되면 `http://localhost:5173`으로 접근할 수 있습니다.

---

## 테스트

```bash
# 린트 실행
npm run lint
```
