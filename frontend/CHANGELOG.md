# 프론트엔드 변경 이력

프론트엔드 운영 릴리스만 기록합니다. 버전은 `vMAJOR.MINOR.PATCH` Git tag와
일치하며, 아직 발행하지 않은 변경은 `Unreleased`에 적습니다.

## Unreleased

## v1.1.1

`dev → main` 반영을 준비하는 릴리스입니다. 운영 배포 검증과 태그 발행 결과는 배포 후 확인합니다.

### 포트폴리오와 AI 분석

- 포트폴리오 자산 추이·거래 내역·종목 상세 패널과 반응형 배치를 개선하고, 그래프 툴팁과 팝업 흔들림을 수정했습니다.
- 비회원의 매수·매도 거래 기록을 지원하고, 회원·비회원의 거래 입력과 보유 자산 관리 화면을 정리했습니다.
- 포트폴리오 분석 결과를 서버에 저장하고 조회·갱신하도록 연결했습니다. 분석 근거 수집 누락과 응답 검증 실패를 보완하고 전체 요약·출처·문체를 개선했습니다.
- 회원의 이전 공용 브라우저 분석 캐시를 사용하지 않고 계정별 서버 결과를 조회합니다. 자산·계정 변경, 동시 분석, 새 근거 확인 실패와 이전 결과 유지 상태를 처리하며 서버는 최근 변경 이력 10개를 제공합니다. 프론트의 분석 이력 탐색 화면은 포함하지 않습니다.
- 자산 추이는 날짜별 평가값과 툴팁을 표시하며 거래 표시점·거래 범례를 제거했습니다. 매수·매도 기록은 거래 내역에서 확인합니다.
- 종가 누락 처리와 과거 스냅샷 재계산을 보완했습니다.

### 소식·검색·주요 인물

- 소식 홈을 이슈·종목 콘텐츠·인물 소식 중심으로 통합하고, 포트폴리오 보유 자산과 관련된 소식을 제공합니다.
- 전체 소식 콘텐츠를 통합 검색 API에 연결하고 검색 화면과 검색창을 개선했습니다.
- 외부 콘텐츠의 발행일 입력·표시와 발행일 기준 정렬을 적용했습니다.
- 게시일 정렬은 소식 홈·전체 콘텐츠의 종목 외부 자료에 적용됩니다. 통합 검색과 종목 상세·보유 자산 소식은 기존 등록 시각 정렬을 유지하며, 인물 글 날짜는 원문 게시일이 아닌 API 등록일입니다.
- 주요 인물의 프로필 이미지와 YouTube 채널 연결을 지원하고, 인물 프로필 화면과 파비콘을 변경했습니다.
- 뉴스 상세 키워드 팝업과 시장 분석 화면을 개선하고, 원문 기반 키워드 분석과 시장 분석 문장부호 처리를 보완했습니다.
- 로컬 개발 서버에만 소식 화면 확인용 샘플 기사를 표시하고 배포 빌드·테스트에서는 제외합니다.

### 투자 리그

- 투자 리그·공개 프로필·참여 설정 화면을 임시로 ‘준비 중’ 안내로 전환했습니다. 아래 리그 집계·조회 변경은 코드에 포함되며, 현재 화면에서는 제공하지 않습니다.
- 주간 리그는 첫 집계 종가를 0% 기준으로 삼고, 매일 수익률을 복리로 누적해 순위를 갱신합니다. 다음 주에는 주간 누적을 새로 시작합니다.
- 리그와 공개 프로필의 조회 범위를 최근 3주로 통일하고, 일별 성과는 날짜·하루 수익률·주간 누적 중심으로 표시합니다.
- 리그 이동과 공개 프로필·참여 설정을 간소화하고, 리그 종목 삭제를 추가했습니다. 마지막 종목을 삭제하면 참여를 종료합니다.
- 리그 순위에 종가 기준 가상 성과가 실제 투자 수익률과 다를 수 있음을 안내합니다.

### 사용성·분석 이벤트

- 서비스 전반의 화면 구성·반응형 UI와 마이페이지를 개선했습니다.
- 이슈·인물·포트폴리오 대시보드·포트폴리오 분석·키워드·시장 분석의 사용자 행동 이벤트를 추가하고, 프론트엔드 배포에 PostHog 설정을 연결했습니다.
- 통합 검색 테스트 컴파일 오류와 시장 분석 이벤트 테스트의 CI 실패를 수정했습니다.
- 회원 서버 저장과 비회원 임시 저장, 통합 검색·분석 기능에 맞춰 서비스 소개·이용 안내·개인정보 안내를 갱신했습니다.

### 배포·관련 문서

- 프론트 패키지와 잠금 파일 버전을 `1.1.1`로 맞췄습니다. README·릴리스 절차·소식 디자인 계약과 백엔드 README·리그 모니터링 안내를 현재 코드에 맞췄습니다.
- 함께 반영할 DB 마이그레이션은 V35~V42입니다. 분석·근거 저장과 동시 요청 상태, 콘텐츠 게시일·인물 프로필 이미지·YouTube URL을 추가합니다. V42는 게시일 없는 기존 외부 자료를 한국 시간 등록일로 채우고 정렬 인덱스를 추가하며 원문 게시일을 새로 수집하지 않습니다. 신규 자료도 게시일 입력을 생략하면 한국 시간 등록일을 저장합니다.
- 배포 Environment의 `VITE_POSTHOG_KEY`·`VITE_POSTHOG_HOST`가 모두 설정되면 명시적 행동 이벤트를 전송합니다. 자동 수집·세션 녹화는 사용하지 않습니다.
- 버전 준비는 이슈 [#451](https://github.com/woowacourse-teams/2026-DAYNOMY/issues/451)에서 진행합니다. 개발·운영 적용 순서와 수동 확인 범위는 [RELEASING.md](RELEASING.md#v111-반영-순서)를 따릅니다.

## v1.1.0

### 포트폴리오와 거래 기록

- 포트폴리오를 기본 진입 화면으로 변경하고 평가금액·평가손익·일간 손익·자산 구성을 확인하는 대시보드와 보유 종목 필터·정렬을 정리했습니다.
- 회원의 자산 추이를 실제 API에 연결하고 기간별 그래프와 상세 정보를 제공합니다. 시세 누락·기준일 혼재·추이 조회 실패를 구분하고 해당 영역에서 재시도할 수 있습니다.
- 매수·매도 거래 등록·수정·삭제와 종목별 거래 내역을 추가했습니다. 기존 보유자산 등록·보유정보 정정·제거는 거래 기록과 구분하며, 수수료·세금을 포함한 거래 정보를 입력합니다.
- 평가손익과 누적 실현손익을 구분하고, 전량 매도 후에도 과거 자산 추이와 거래 내역을 유지합니다. 거래 변경 후에는 보유자산·손익·내역·추이를 함께 갱신합니다.
- 보유 종목의 상세 패널에서 종목 정보와 관련 소식을 확인하고 거래 입력으로 이동할 수 있습니다. 매수·매도 입력을 같은 패널에서 전환하고 취소하면 상세 화면으로 돌아옵니다.
- 비회원도 종목을 추가·정정·제거하고 현재 평가금액·손익·자산 구성을 확인할 수 있습니다. 보유정보는 현재 브라우저 세션에 임시 저장하며, 회원 전용 자산 추이·거래 내역·실현손익은 로그인 후 제공합니다.
- 비회원 임시 저장에 실패하면 기존 보유정보와 입력을 유지하고 재시도를 안내합니다. 로그인 후에는 계정 포트폴리오를 조회하며 임시 보유정보를 자동 이전하지 않습니다.

### 포트폴리오 AI 분석

- 포트폴리오 대시보드에 AI 분석을 연결하고 자산별 결과·출처·가중 영향 점수와 산정 기준을 표시합니다. 비중이 0인 자산은 분석 대상에서 제외합니다.
- 회원의 당일 분석 결과를 브라우저에 저장해 화면에 다시 진입할 때 재사용합니다. 보유 종목이 바뀌면 기존 결과를 확인한 뒤 다시 분석할 수 있으며, 날짜가 지나거나 저장 데이터가 잘못되면 재사용하지 않습니다.
- 비회원에게 AI 분석 1회 체험을 제공하고 결과와 체험 상태를 세션에 보관합니다. 분석 실패 시 재시도를 허용하고 체험 소진 시 로그인을 안내합니다. 모든 보유자산을 제거하면 저장된 분석 결과를 지웁니다.
- 자산별 분석과 출처의 표시 방식·글자 위계·줄바꿈을 정리하고, 본문 너비에 맞춰 분석 영역과 소식 패널의 배치를 조정했습니다.

### 투자 리그와 공유 포트폴리오

- 공유 포트폴리오·리그 참여와 공개 설정·주간 순위·투자자 공개 상세·관심 투자자 화면을 실제 API에 연결했습니다.
- 리그 종류를 주간 수익률·안정형·초보리그 세 가지로 정리했습니다. 최근 8주 조회와 상세 성과 지표는 유지합니다.
- 순위 상세 지표는 옆 패널에서, 투자자 성과·공개 종목·투자 기록은 탭으로 확인합니다. 리그 설정은 리그와 마이페이지에서 바로 열 수 있습니다.
- 종목별 보유 판단과 결과 복기를 작성·저장·재조회할 수 있습니다. 보유 이유만 필수이고 나머지 판단 정보와 복기는 선택이며, 저장 실패 시 초안을 유지하고 재시도할 수 있습니다.
- 주중 신청 이후 성과와 다음 월요일부터의 공식 순위를 구분하고 전체 누적·최근 8주·연속 기록 주차를 표시합니다. 미참여·누락 주차와 데이터 부족을 숨기지 않으며 평가액 10만 원 조건을 제거했습니다.
- 확정된 주간 순위의 버전·종가 기준일, 프로필 이미지, 현재 집중도와 종목별 평가 수익률을 연결했습니다. 위험 지표 기간과 복리 기여도 안내를 수정하고 순위를 20개씩 조회합니다.
- 관심 투자자 요약에 지난주 확정 순위 대비 상승·하락·동일을 표시하고 비교 기록이 없으면 별도로 안내합니다.
- 공유 포트폴리오를 원본 불러오기와 숨김·해제 전용으로 변경했습니다. 직접 추가·자산 편집·삭제·거래 입력 API를 제거하고 기존 자산과 판단·복기 기록은 보존합니다.
- 원본을 수정한 뒤 다시 불러올 때 확인을 거쳐 공유 정보를 갱신합니다. 숨김과 판단·복기 작성은 원본 자산의 수량·매수가를 변경하지 않습니다.
- 멤버십 화면·권한 검사·체험·7일 지연을 제거하고 공개 종목·판단·복기를 비회원에게도 즉시 제공합니다. 기존 공개 동의와 숨김은 유지하며 종가 없는 종목의 지표는 집계 대기로 표시합니다.
- 리그 조회의 주차 오류·집계 조건 안내를 보완했습니다.

### 로그인·마이페이지·탐색

- 기존 Google 로그인과 실제 계정 API를 연결하고 로컬 OAuth 프록시를 추가했습니다. 로그인 복귀 경로를 검증해 보던 화면으로 돌아가도록 개선했습니다.
- 마이페이지의 비공개 이메일·Google 계정 이름과 공개용 닉네임을 분리했습니다. 닉네임 변경·중복 검사는 헤더와 리그에 동일하게 반영하고 재로그인해도 유지합니다.
- 서비스 헤더와 마이페이지·리그 메뉴를 추가하고 로그인 화면의 푸터와 복귀 동선을 정리했습니다. 일반 페이지 이동 시 스크롤 위치를 초기화합니다.
- 초보 돈 관리 메뉴와 화면 진입을 제거했습니다. 기존 주소는 홈으로 이동하며 저장된 기록은 삭제하지 않습니다.

### 뉴스·종목 소식·주요 인물

- 뉴스 상세의 키워드와 시장 분석 UI를 개선했습니다. 시장 분석이나 키워드 조회가 실패해도 뉴스 본문은 유지하고, 데이터 없음과 오류를 구분해 안내합니다.
- 뉴스 이미지의 출처·저작자·라이선스 정보를 표시하고 이미지 유형에 맞는 안내를 제공합니다.
- 종목별 관련 자료 화면과 보유 종목 소식 패널을 추가했습니다. 보유 종목 사이를 이동하고 YouTube·Threads·X·DAYNOMY 이슈 등 출처별로 자료를 확인할 수 있습니다.
- YouTube 영상은 선택한 영상만 모달에서 재생하고, Threads·X 게시물은 공식 임베드와 원문 링크를 제공합니다. 지원하지 않는 영상 URL은 링크로 표시합니다.
- 주요 인물 소식 화면에서 최근 발언·전체 인물 목록·선택한 인물의 게시물을 확인하고 이름으로 검색할 수 있습니다.

### 관리자 기능과 피드백

- 관리자 뉴스 목록에 검색을 추가하고 페이지·상태 필터 변경에도 검색 조건을 유지합니다. 뉴스 등록·수정 화면에서 관련 종목을 선택할 수 있습니다.
- 관리자 뉴스 이미지에 Wikimedia Commons 검색·선택을 추가했습니다. 이미지와 종목 검색은 최신 요청의 결과만 반영하도록 보완했습니다.
- 관리자 종목 관련 자료의 등록·삭제와 출처별 필터를 추가했습니다. YouTube·Threads·X 자료를 검색하고 선택한 URL을 등록할 수 있습니다.
- 관리자 주요 인물·게시물 관리 화면을 추가했습니다. 게시물 URL 미리보기와 X·Threads 검색 결과의 연속 등록을 지원합니다.
- 현재 화면에서 의견을 보낼 수 있는 피드백 위젯과 관리자 피드백 목록·처리 상태 변경·삭제 화면을 추가했습니다.

### 사용성·검증·배포

- 포트폴리오 입력창의 초기 포커스와 패널 전환·닫기 시 포커스 복귀를 보완했습니다. 삭제 확인은 상세 패널 안에서 처리하고 실패 시 확인창과 내역을 유지합니다.
- 포트폴리오 소식 패널의 반응형 잘림과 큰 금액 그래프 툴팁의 넘침을 수정했습니다.
- 작성자 이름과 숫자 기반 명칭을 기능명으로 정리하고 브라우저 저장 키의 읽기 호환을 보존했습니다. 중복 페이지 진입 컴포넌트와 사용하지 않는 리그 스타일을 제거했습니다.
- 포트폴리오 분석과 검색 열기·리그 행동의 분석 이벤트를 보완했습니다. 투자자 식별자와 판단 원문은 분석 URL과 이벤트에 보내지 않습니다.
- 로그인 복귀·비회원 체험·거래 기록·반응형 패널을 검증하는 테스트를 보완하고, 기간별 자산 추이 테스트의 기준 날짜를 고정했습니다.
- 프론트 배포의 GHCR 로그인·이미지 다운로드 단계를 분리하고 시간 제한을 추가했습니다. 개발·운영 러너의 상태와 연결을 읽기 전용으로 확인하는 진단 절차를 마련했습니다.
