# 프론트엔드 변경 이력

프론트엔드 운영 릴리스만 기록합니다. 버전은 `vMAJOR.MINOR.PATCH` Git tag와
일치하며, 아직 발행하지 않은 변경은 `Unreleased`에 적습니다.

## Unreleased

- 순위 상세 지표 패널, 투자자 상세 탭, 종목별 보유 이유·복기 작성과 리그 설정을 최신 UI로 통일하고 실제 API에 연결했습니다. 보유 이유만 필수로 받고 나머지 판단 정보는 선택으로 저장합니다. 중복 페이지 진입 컴포넌트와 사용하지 않는 리그 스타일을 제거했습니다.

- 리그 종류를 주간 수익률·안정형·초보리그 세 가지로 정리했습니다. 최근 8주 조회와 상세 성과 지표는 유지합니다.

- 관심 투자자 요약에 지난주 확정 순위 대비 상승·하락·동일을 표시하고 비교 기록이 없으면 별도로 안내합니다.

- 주중 신청 이후 성과와 다음 월요일부터의 공식 순위를 구분하고 전체 누적·최근 8주·연속 기록 주차를 표시합니다. 미참여·누락 주차와 데이터 부족을 숨기지 않으며 평가액 10만 원 조건을 제거했습니다.
- 확정된 주간 순위의 버전·종가 기준일, 프로필 이미지, 현재 집중도와 종목별 평가 수익률을 연결했습니다. 위험 지표 기간과 복리 기여도 안내를 수정하고 순위를 20개씩 조회합니다.
- 리그 행동 이벤트를 명세에 맞추고 투자자 식별자·판단 원문을 분석 URL과 이벤트에 보내지 않도록 보완했습니다.

- 공유 포트폴리오를 원본 불러오기와 숨김·해제 전용으로 변경했습니다. 직접 추가·자산 편집·삭제·거래 입력 API를 제거하고 기존 자산과 판단·복기 기록은 보존합니다.
- 멤버십 화면·권한 검사·체험·7일 지연을 제거하고 공개 종목·판단·복기를 비회원에게도 즉시 제공합니다. 기존 공개 동의와 숨김은 유지하며 종가 없는 종목의 지표는 집계 대기로 표시합니다.
- 마이페이지의 비공개 이메일·Google 계정 이름과 공개용 닉네임을 분리했습니다. 닉네임 변경·중복 검사는 헤더와 리그에 동일하게 반영하고 재로그인해도 유지합니다.
- 초보 돈 관리 메뉴와 화면 진입을 제거했습니다. 기존 주소는 홈으로 이동하며 저장된 기록은 삭제하지 않습니다.
- 기존 Google 로그인과 실제 계정 API를 연결하고 로컬 OAuth 프록시를 추가했습니다.
- 작성자 이름과 숫자 기반 명칭을 기능명으로 정리했습니다. 클래스·모듈·API·CSS·새 저장 키·마이그레이션 파일명까지 변경하고, 공식 DB 이력과 충돌하지 않도록 신규 기능은 `V22~V26`로 재배정했습니다. 기존 데이터 이전은 별도 승인 범위이며 브라우저 저장 키는 읽기 호환으로 보존합니다.
- 공유 포트폴리오 안에서 보유 판단과 결과 복기를 작성·저장·재조회할 수 있도록 연결했습니다.
- 원본 및 공유 자산 수량을 변경하지 않는 판단 기록과 저장 실패 시 초안 유지·재시도를 추가했습니다.
- 로그인 복귀 경로를 검증해 보던 화면으로 돌아가도록 개선했습니다.
- 리그 조회의 주차 오류·집계 조건 안내를 보완했습니다.

## v1.0.0

- 첫 프론트엔드 운영 릴리스 기준을 정했습니다.
- 배포 이미지와 Sentry release에 동일한 버전을 기록하고 이전 이미지 재배포 절차를 마련했습니다.
