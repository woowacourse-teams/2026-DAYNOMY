# PMF 설문 정책안 v2 — FE #805

상태: 사용자 승인 후 FE #805에 적용. 단일 POST, 닫기/오늘 숨김 분리, 첫 대시보드 진입 시 노출을 프론트에 반영했다. 서버 저장과 집계는 BE #809에서 구현한다. 계약은 `pmf-survey-api.md`를 따른다.

## 목적과 설문 대상

- 팀 밖 일반 사용자에게 설문 참여 기회를 제공한다. 기존 팀원 제외 정책을 적용하고 관리자·팀원 도메인에는 노출하지 않는다.
- 일반 응답을 수집하되 **공식 PMF 집계는 응답 시점 기준 최근 2주 내 포트폴리오 분석 버튼을 누른 사용자**로 제한한다.
- 신규/재방문 여부와 분석 사용 여부는 별개다. 분석 미사용 응답은 공식 PMF 결과와 구분한다. 과거 이력 확인 불가를 미사용으로 단정하지 않는다.

## 시안과 입력

- PC 너비 약 500px, 제목 24px, 본문 15~16px, 내부 여백 24px, 응답 행 최소 44px. 모바일은 화면 양쪽 여백을 확보하고 작은 높이에서는 팝업 내부 스크롤을 허용한다.
- 고정 문항과 선택지는 변경하지 않는다.

> 이 제품을 더 이상 쓸 수 없다면 어떻겠습니까?
>
> - 매우 실망
> - 약간 실망
> - 실망하지 않음
> - 더 이상 쓰지 않음

- 기본 선택값은 없다. 필수 선택지 하나를 고르면 `응답 보내기`를 사용할 수 있다.
- 선택 질문 `그렇게 답하신 가장 큰 이유는 무엇인가요? (선택)`과 500자 이내 입력란은 **항상 표시**한다. 의견 없이도 제출할 수 있으며 빈 값/공백은 `null`로 정규화한다. 입력된 의견은 제출 본문에 포함한다.
- 주 버튼은 `응답 보내기` 하나다. 하단에는 `오늘 하루 그만 보기`와 `닫기`를 각각 둔다. 상단 X는 `닫기`와 같은 동작이며 영구 숨김 버튼은 만들지 않는다.

## 최초 노출

- 첫 방문자와 재방문자는 포트폴리오 대시보드에 진입하면 같은 조건으로 설문을 본다. 비회원 서비스 소개 화면에서는 ‘시작하기’를 눌러 대시보드에 들어간 뒤 표시한다.
- 서버는 응답 저장 시점에 최근 14일 내 수동 포트폴리오 분석 요청 기록을 확인해 집계 그룹을 정한다.

## 노출 위치와 두 가지 닫기 동작

| 상황/행동                                   | 동작 및 다음 노출                                                                            |
| ------------------------------------------- | -------------------------------------------------------------------------------------------- |
| 대상 사용자의 포트폴리오 대시보드(`/`) 진입 | 미응답·미숨김 상태라면 팝업 표시                                                             |
| 소식·투자 리그 등 다른 화면 이용            | 팝업 표시하지 않음                                                                           |
| X 또는 `닫기`                               | 현재 팝업만 닫음. 답변을 저장하거나 오늘 숨김을 설정하지 않음                                |
| 닫은 뒤 같은 대시보드에서 계속 이용         | 다시 열지 않음. 타이머·데이터 재조회·컴포넌트 재렌더링도 재노출 사유가 아님                  |
| 다른 서비스 화면에서 대시보드로 돌아옴      | 조건을 다시 확인하고 미응답·미숨김이면 재노출. 브라우저 뒤로/앞으로 이동도 포함              |
| 대시보드 새로고침 또는 새 방문              | 조건을 다시 확인하고 미응답·미숨김이면 재노출                                                |
| 브라우저 탭 재활성화·창 포커스 복귀         | 이것만으로 닫았던 팝업을 다시 열지 않음                                                      |

| 자정 경과                                   | 다음 대시보드 진입·새로고침 때 노출 가능. 자정에 사용 중인 화면 위로 자동 팝업을 띄우지 않음 |
| 응답 저장 성공                              | 해당 설문 재노출 종료                                                                        |

- **하루 최대 1회·24시간 간격·총 2회 제한은 적용하지 않는다.** X로 닫은 미응답자는 같은 날에도 대시보드 재진입 시 다시 참여할 수 있다.
- `나중에`는 별도로 두지 않는다. 다음 노출 의미가 모호하지 않도록 `닫기`와 `오늘 하루 그만 보기`를 사용한다.
- 설문 캠페인이 종료되면 모든 자동 노출을 중단한다.

## 오늘 숨김의 시간과 저장

- 기준 시간대는 사용자 기기 설정과 무관하게 `Asia/Seoul`이다. 24시간 후가 아니라 **다음 날짜의 00:00:00**에 만료한다.
- 예: 2026-11-05 23:50 KST 선택 → 2026-11-06 00:00 KST 만료. 만료 후에도 다음 대시보드 진입 전까지 팝업을 자동으로 열지 않는다.
- 숨김은 `설문 캠페인 + 응답자` 단위다. 다른 계정이나 다른 캠페인으로 잘못 이어지지 않게 한다.
- 회원은 서버에서 숨김 기한을 관리해 기기 간 적용한다. 비회원은 BE가 발급한 익명 식별자 기준으로 적용하고, 같은 브라우저에서는 탭·새로고침 간에도 유지한다. 다른 기기의 비회원을 같은 사람으로 보장하지 않는다.
- 숨김 저장 실패 시 확정된 것처럼 안내하지 않는다. 현재 브라우저에서 기한을 유지할 수 있으면 로컬 숨김을 적용하고, 계정 전체 적용 실패는 재시도할 수 있도록 알린다. 브라우저 저장도 불가능하면 해당 화면을 닫되 지속 숨김이 실패했음을 안내한다.
- 응답 본문과 선택 이유는 브라우저 저장소에 보관하지 않는다.

## 제출 방식 — 단일 POST

```json
{
  "answer": "VERY_DISAPPOINTED",
  "reason": null
}
```

- `POST /api/pmf-surveys/{surveyId}/responses` 한 번에 필수 응답과 선택 이유를 저장한다. `응답 보내기`를 누르기 전에는 응답을 생성하지 않는다.
- 별도 이유 PATCH와 두 번째 제출 화면은 제거한다. 오늘 숨김 설정은 `POST /api/pmf-surveys/{surveyId}/snooze`로 처리한다. 서버가 KST 다음 자정을 계산하며 응답을 생성하지 않는다.
- 서버는 캠페인/응답자 단위 중복을 방지하고 동일 요청 재시도 시 기존 응답을 반환한다. 공식 집계 그룹, 응답 시각, 모집 경로 `IN_APP`은 서버가 확정한다.
- 저장 중에는 중복 제출과 닫기를 막는다. 성공 시 완료 안내 후 종료하며, 실패하면 선택·의견을 유지하고 재시도할 수 있다.
- 제출 전 닫기·오늘 숨김·화면 이탈은 응답을 남기지 않는다. 따라서 중간 선택 보존은 사라지지만, 추가 화면이나 두 번째 제출을 요구하지 않는다. 실제 응답률 변화는 측정 후 판단한다.

## 검증 및 집계

- 첫 방문과 재방문 모두 첫 대시보드 진입에서 표시되는지 확인한다.
- X/닫기 후 같은 화면 유지 시 미노출, 다른 화면 왕복·새로고침 후 재노출을 확인한다.
- 오늘 숨김 후 탭/새로고침/계정별 분리, KST 자정 경계, 기기 시간대 변경을 확인한다.
- 미선택 제출 차단, 선택 이유 없음/null·500자 제한·기본 표시, 저장 실패 재시도, 중복 클릭·네트워크 재시도를 확인한다.
- 노출 횟수와 고유 노출 사용자 수를 분리하고, 공식 PMF 대상/기타/확인 불가 그룹별 응답자 수·선택지별 인원·응답률을 확인한다. 반복 노출 수를 사람 수로 집계하지 않는다.
- 분석 도구에는 상태·횟수 등 필요한 비식별 집계만 전송하고 자유 입력 본문·개인 식별값을 넣지 않는다.
